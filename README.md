# bitwarden-export
Export Bitwarden Vault

## What it does?
Export Bitwarden vault to your WebDAV

## Action secrets
Assign secrets in Settings -> Secrets and variables -> Actions -> New repository secret

| Name                    |
| ----------------------- |
| `BW_SERVER`             |
| `BW_CLIENTID`           |
| `BW_CLIENTSECRET`       |
| `BW_PASSWORD`           |
| `WEBDAV_URL`            | 
| `WEBDAV_USERNAME`       |
| `WEBDAV_PASSWORD`       |
